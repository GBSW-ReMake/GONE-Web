## 구현 요약

로그인·회원가입 성공 이후 인증 상태를 복구하고, 사용자 역할에 맞는 보호 화면으로 이동하는 전체 Web 인증 기반을 구현했다. 백엔드 미연동 환경에서 API 계약과 같은 임시 Mock Fixture로 최종 Web QA를 수행했으며, 담당자 요청에 따라 검증 직후 Mock 코드와 전환 환경변수를 제거했다. 현재 제품 코드는 실제 GONE Server만 호출한다.

## API·권한 처리

- 사용 API: 로그인, 회원가입, `users/me`, 토큰 재발급, 로그아웃, 휴대폰 인증 API
- 역할별 접근: 사용자 역할과 다른 보호 URL은 역할별 첫 화면으로 이동
- 401 처리: Refresh Token 재발급 성공 시 원래 요청 1회 재시도, 실패 시 `/login`
- 403 처리: 실제 도메인 화면 구현 시 서버 응답 기준으로 추가 연결
- 주요 에러 문구: API code·HTTP 404를 한국어 사용자 안내로 변환

## 알려진 제한사항

- 실제 Backend·SMS·학적 DB와의 통합 테스트는 아직 실행하지 않았다.
- 401 재발급은 실제 서버 응답으로 재검증해야 한다.
- 인증번호 5분 만료는 실제 시간 경과가 아닌 코드 경로만 확인했다.
- Mock 폴더를 제거했으므로 이후 인증 QA에는 실행 가능한 Backend와 테스트 학적 데이터가 필요하다.
- 역할별 화면은 현재 인증 경계를 확인하기 위한 임시 홈이며, 실제 역할 도메인 화면은 후속 Issue에서 구현한다.
- 이번 환경에서 Next.js Turbopack이 권한 오류를 내므로 개발·빌드는 Webpack 모드를 사용한다.
