# 인증 흐름

## 로그인

```text
로그인 화면
→ POST /api/v1/auth/login
→ Access Token·Refresh Token 저장
→ 사용자 정보 조회
→ 권한에 맞는 화면 이동
```

## 토큰 만료

```text
API 요청
→ 401 응답
→ Refresh Token으로 재발급
→ 원래 요청 재시도
→ 실패하면 로그아웃 처리
```

## 회원가입

```text
아이디 확인
→ 비밀번호 입력
→ 휴대폰 인증
→ 회원가입
→ 이름 수정
→ 프로필 이미지 업로드
```

회원가입 성공 응답에 토큰이 포함되므로 로그인 API를 다시 호출하지 않는다.
