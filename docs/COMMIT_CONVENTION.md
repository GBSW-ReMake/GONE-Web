# 커밋 규칙

## 형식

```text
type: 한글 설명 (#이슈번호)
```

## 타입

| 타입       | 의미           |
| ---------- | -------------- |
| `feat`     | 새 기능        |
| `fix`      | 버그 수정      |
| `ui`       | UI 변경        |
| `refactor` | 구조 개선      |
| `chore`    | 설정·관리 작업 |
| `test`     | 테스트         |
| `docs`     | 문서           |

예시:

```text
feat: 로그인 화면 구현 (#3)
chore: pnpm 설정 추가 (#2)
docs: 외출증 API 문서 작성 (#5)
```
