# 라우트 맵

## 초기 라우트

| 경로             | 화면       | 인증   | 주요 역할          |
| ---------------- | ---------- | ------ | ------------------ |
| `/login`         | 로그인     | 불필요 | 전체               |
| `/signup`        | 회원가입   | 불필요 | 전체               |
| `/`              | 홈         | 필요   | 전체               |
| `/outing`        | 외출증     | 필요   | 학생·교사·선도부   |
| `/schoolcamp`    | 스쿨캠핑   | 필요   | 학생·관리 역할     |
| `/conduct`       | 상점·벌점  | 필요   | 학생·관리 역할     |
| `/meal`          | 급식       | 필요   | 전체 로그인 사용자 |
| `/timetable`     | 시간표     | 필요   | 전체 로그인 사용자 |
| `/notifications` | 알림       | 필요   | 전체 로그인 사용자 |
| `/mypage`        | 마이페이지 | 필요   | 전체 로그인 사용자 |
| `/admin`         | 관리자     | 필요   | `ADMIN`            |

실제 세부 경로와 역할은 기능 구현 전에 Notion·백엔드 명세로 확정한다.

## 라우트 구성 규칙

- 공개 라우트: 로그인하지 않아도 접근할 수 있다.
- 보호 라우트: 인증이 없으면 `/login`으로 이동한다.
- 역할 라우트: 인증과 역할을 모두 확인한다.
- 존재하지 않는 경로: 공통 404 화면을 보여준다.
- 마지막 방문 경로가 필요하면 안전한 내부 경로인지 검증한 뒤 복귀시킨다.

## 화면 추가 시 기록할 항목

- 경로와 URL 파라미터
- 페이지 제목과 진입 경로
- 로그인 필요 여부
- 허용 역할
- 로딩·빈·오류·권한 거부 화면
- 이탈 또는 저장하지 않은 입력값 처리
