## 테스트 방법

1. `pnpm install`로 의존성을 설치한다.
2. `pnpm dev`로 웹을 실행한다.
3. 대상 URL에 진입한다.
4. 테스트 계정 역할과 수행한 행동을 작성한다.
5. 예상 결과와 실제 결과를 확인한다.
